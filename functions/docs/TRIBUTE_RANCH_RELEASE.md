## 互換性と限界

- 本番の HTML は `Cache-Control: max-age=3600` のため、公開前に開いていた人は最大1時間ほど旧画面になりうる。旧画面から管理人カードを保存すると、Xプロフィール欄がないためリンクは付かない（既存のリンクは消える）。新画面で付け直せる
- 実績の引き継ぎは貢ぎ帳から確実に言える下限だけで、実際の献上日数より少なく数えることがある
- iPhone／Android 実機、Safari での確認は行っていない
