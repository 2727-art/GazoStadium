# 通常型1on1のスマホ画像保存（2026-11-12）

本番と一致する main `4c43c11` を起点に、通常型1on1の画像保存だけを追加。

- DMスレッド・見つめるモード・画像の拡大表示の長押し／画像メニューを許可。
- 見つめるモードのヘッダーと「画像だけ」の操作欄、拡大表示に「画像を保存」を追加。過去ラウンドを見ている場合は、その画像を保存する。
- 受信済みBlobを再圧縮せず、JPEG・PNG・WebPの形式を保って端末へダウンロードする。保存先はブラウザ設定による。写真アプリへの保存は端末の長押しメニューなどを利用する。
- ダウンロード用URLは画面を閉じても60秒保持する。拡大画像の表示用URLは閉じる時に破棄し、準備中の読み込みは中断する。
- 保存ボタンを押しても拡大画面は閉じない。拡大画像の背景・閉じるボタン・Escapeで閉じる。
- 配信更新キーは `mobile-image-save-v1`。本番の遅延読み込みmanifestにも付与する。
- Firebaseへの書き込みやサーバー保存、バックエンド・ルール変更はない。既存の旧URL転送とウォレット移行入口を維持する。
