# 1on1ランキングの期間限定化（2026-11-04）

## 変更内容

- 通常型・戦略型1on1の公開ランキングをデイリー・ウィークリー・マンスリーの3種類にする。
- 総合RATE TOP10、下限チャレンジ、下限参加設定、総合RATEクラス／BEYOND表示を撤去。
- 「あなたの現在地」の総合順位、参加母数、上位割合、前後3人、自己最高順位の読み取り・計算・更新を停止。三戦証明と王座の見せ方は維持。
- 総合・下限の公開ミラーと総合ミラーのUID索引への読み書きをRealtime Database Rulesで拒否。旧下限参加APIもDBアクセス前に終了エラーを返す。
- 試合確定、参加設定、王座カスタマイズ、実績ショーケース更新、ランキング実績同期から廃止ミラーの更新を除去。下限同期用revisionも更新しない。
- 競技RATEと検証済み試合数の正本は維持し、正式対戦で更新する。三戦証明の開始値・期待勝率・同点判定など、期間ランキングの計算は従来どおり。
- 準備画面の `get_ranking_dashboard` はプロフィールと当日のrunだけを読む。ランキング画面は `includePresentation: true` を指定して、王座設定の選択肢とスポットライトを追加取得する。
- デイリー／ウィークリー表示時の月間一覧の先読みを廃止。月間を選択すると従来のキャッシュと開幕進捗取得を使う。
- 日付変更・タブ復帰時の自動ダッシュボード取得は、表示中のランキング画面または1on1準備画面に限定。トップ・対戦中・他機能・非表示タブでは開始しない。
- 通常型／戦略型の準備画面への入場・再入場・タブ復帰で三戦証明を更新。同じ画面の描き直しでは再取得しない。重複要求は共有し、認証待ち中に画面を離れた場合は取得を中止する。すでに送信済みの通信は完了する。
- 期間一覧もランキング画面の表示中だけ取得し、三戦証明開始や設定保存後に準備画面・トップへ先読みしない。
- コメント、X設定、確定済み週間履歴、歴代月間王者、期間ランキング実績は維持する。

## 保持データ

既存RATEや過去の期間成績は削除・リセットしない。廃止した公開ミラーの既存データは読み取り禁止にし、物理削除は行わない。
`online/leaderboard` とその所有者索引は、期間参加・公開プロフィールの本人確認・コメント・ブロック確認でも使用するため維持する。総合順位の一覧取得には使わない。

本番の読み取り削減率は未測定。Firebase全体の削減率はランキング閲覧・対戦準備の利用頻度による。

## リリース

本番の最新版（`cc331a6`）を基に今回の変更を統合。期間限定化を本番へ反映するにはCloud Functions、Realtime Database Rules、Hostingをすべてデプロイする必要がある。画面に限定する取得制御はHosting側の変更。ブラウザーのapp／online／strategyには `period-rankings-only-v1` と `ranking-screen-load-v1` のキャッシュ更新キーを付与済み。
旧画面では廃止一覧の読み取りが拒否されるため、更新後の画面へ再読み込みが必要になる。
