# お貢ぎ牧場：牧場の飾りの枠の色（2026-10-09）

## 対応内容

牧場の飾りの公開後、ユーザーから「最終的に全員玉座になり、差別化がなくなる」との指摘。枠ごとに色を選べるようにした。

- 枠ごとに5色。持っている枠なら、どの色も追加料金なしで選べる（ユーザー決定。ストアの品は増えない）
- どの枠にもピンク系を入れる（ユーザー決定）。ピンクは各枠の2番目に並べる。1色目は色を選ぶ前の見た目で、いまのカードは変わらない
  - 黒革: 黒・ピンク・焦げ茶・ボルドー・濃紺
  - 鎖: 銀・ピンクゴールド・金・黒鉄・クローム青
  - 薔薇とレース: 赤薔薇・桃薔薇・黒薔薇・白薔薇・青薔薇
  - 金縁の額: 金・ピンクゴールド・銀・ローズゴールド・黒金
  - 玉座: 深紅・ピンク（ピンクゴールドの縁と冠）・漆黒・紫紺・瑠璃（銀の縁と冠）
  - 5色に収めるため、深緑（黒革）・翡翠（玉座）・白金（金縁、銀と見分けにくい）を外した（ユーザー了承）
- 背景はどの色でも暗いまま（白い文字が読めるように）。色は背景・金属・飾りの絵だけを変え、文字の色と位置、中の人の札・入場料・管理中の人数には触れない
- カードの編集: 枠の下に、その枠の5色の丸を出す。選ぶと「掲示板での見え方」と枠の見本がすぐ変わる。持っていない枠を試着中でも色を選べる（保存は買ってから）。「試着をやめる」で、保存してある枠と色に戻る。幅375pxで5つが1行に収まる
- 選んだ色は、掲示板・管理人の詳細・招待リンクで着いた画面・財布募集の画像に出る
- サーバー: 管理人カードに `frameColor` を持ち、枠ごとの一覧（`FRAME_COLORS`）にない色はその枠の1色目にする。色を変えても、持っている必要があるのは枠だけ
- 仕組み: `tribute.css` の枠は `var(--fr-…)` で描き、色ごとの値（鎖・レース・薔薇・金縁の飾り・冠の絵を含む）は `tribute-deco.mjs` の `frameAttr` が、使う色の分だけ `<style id="tribute-frame-colors">` へ足す。財布募集の画像（canvas）も同じ色の表から描く

- 実装コミット: `64898f5`、確認スクリプト: `727724a`（origin/main）
