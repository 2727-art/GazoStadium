# 文字コラトレーニング ブラッシュアップ（2026-09-30）

## 対応内容

ユーザーが作った台本を画像の上に重ねる「文字コラトレーニング」を、提案8項目すべてについて改修した。保存先の指定（マイ台本・作品はどちらも端末内のみ、文字の位置は画像ごとに選択）はユーザーの回答どおり。BPM・時間・停止・安全表示・決済・記録の仕組みは変えていない。

- 実装コミット: `9fa78de`（origin/main）
- 文字の分け方: 台詞を1〜3個の塊に分ける位置を、句読点・空白の直後、単語の境目、文字種の変わり目の順で選ぶ。句読点・閉じ括弧・長音・小書き仮名の前、開き括弧の後では切らない（例:「リズムがき｜れいだよ」→「リズムが／きれいだよ」）。台本の行へ `/`（全角 `／` 可）を入れると、その位置で分ける。`/` は表示時に幅のない区切り（U+200B）へ置き換えて画面に出さない
- 文字の位置: 準備画面の各ロスター画像で「おまかせ／上／下」を選べる。「上」「下」は文字を横書きで上側・下側の帯へ寄せ、画像の中央を空ける。ロスターの端末保存（IndexedDB record schema 2 の各項目に `placement`）、セッション（`placements`）、作品記録（`placement`）へ保存する
- 画像上の「R1 · 80 BPM」表示: 文字と重なるため、全面デコでは表示しない（ラウンドとBPMはHUDと作品キャプションに残る）
- 台本エディタ: 準備画面の1枚目の画像の上に、本番と同じ文字コラで台詞を重ねるプレビューを追加（5構図と文字の位置を切り替え可、分け方も文字で表示）。書きかけの端末内自動保存と復元、場面ごとの状態表示、全体の「○/14場面OK」、「標準の台詞を入れる」「上の場面をコピー」「空いている場面に標準の台詞を入れる」を追加
- マイ台本: 公開せずにこの端末の localStorage（`hariai-ai-text-training-my-scripts-v1`、最大20本）へ保存し、無料で遊べる。準備画面から「この台本で遊ぶ／編集／削除」。販売したい時は従来どおり公開する
- 作品の保存: 結果の各作品に「画像で保存」を追加。画面外で360×560に組み直した文字コラを測り、Canvasへ3倍で描き直した JPEG（1080×1680、`mojikora-roundN-YYYYMMDD.jpg`）を端末へダウンロードするだけで、投稿・共有・サーバー送信はしない

## 互換性と限界

- 本番の HTML と静的ファイルは `Cache-Control: max-age=3600` のため、公開前にページを読み込んでいた人は、最大1時間ほど旧画面、または旧いスタイルと新しいスクリプトが混ざった見た目になりうる。保存データの追加項目は任意なので、旧画面との行き来で記録や有料利用の復旧は壊れない
- `ai-text-training-roster.mjs` はキャッシュキーなしで `ai-text-training-core.mjs` を読み込むが、使うのは変わっていない `AI_TEXT_TRAINING_ROUND_COUNT` だけ
- iPhone／Android 実機、Safari での確認は行っていない。iOS では「画像で保存」でダウンロードの確認が出ることがある
- 「画像重視」（クラシック表示）で遊んだ作品の画像保存は、実際には試していない
