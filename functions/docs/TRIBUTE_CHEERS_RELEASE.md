# お貢ぎ牧場：貢がれ総額の番付・ハートの札・応援欄（2026-10-27）

## 対応内容

ユーザーの考え: お貢ぎ牧場は管理人がいて成り立つ。AnjuPay は換金できないので、飽きた管理人は戻ってこない。本格的なお貢ぎは X の DM が向くので、牧場は管理人と財布のマッチングの場として育てる。管理人に続ける理由を作る。

ユーザーの決定:
- ① 貢がれ総額の番付は当月で、水増し対策を付ける
- ② 応援欄は管理人の詳細に置き、今月貢いだ財布だけが書ける。管理人はコメントを隠せて、「見たよ」の印を返せて、新しい応援が「やること」に出る
- ③ 管理人のカードに順位5位までの札を出し、1位になるほどハートが豪華になる。順位は貢がれ総額で決める

実装:
- 番付の画面を「番付加算」（これまでの番付、最初に開く方）と「貢がれ総額」のタブで切り替える。貢がれ総額は、当月に貢がれた額（`tributeManagerMonths.receivedGross`、手数料を引く前）の多い順で、上位10まで
  - 当月に財布3人以上から貢がれた管理人だけを載せる
  - 10位以内は、カードの X プロフィールと番付のひとこと（カードの `rankingWord`、40文字まで、カードの編集で書く）を出す
- ハートの札: 貢がれ総額の1〜5位に、掲示板のカードと管理人の詳細で出す。5位は輪郭、4位は塗り、3位は艶、2位はローズゴールドと光、1位は王冠と金の縁で光る。上位5人は `tributeRankCache/gross-{monthKey}` に残し、10分まで使う。数えられない時は札を出さず、掲示板は止めない
- 応援欄: 今月その管理人に貢いだ財布（入場料を含む）だけが書ける。40文字まで、書くのは1日3回まで（消すのは数えない）。今月の献上額の多い順で、額は出さない。月が変わると空になる
  - 管理人は「見たよ」（誰にでも見える）・隠す・戻すができる。隠した応援は管理人と書いた財布にだけ見え、その月のあいだは書き直しても隠れたまま。書き直した応援は、また「見たよ」待ちになる
  - 「見たよ」待ちの数を、契約の画面の「やること」に「応援」として出す（`tributeProfiles.cheerInbox`）。「見たよ」は管理人が動いたことに数え、掲示板で上に並ぶ
- 番付のひとことと応援は、今日のひとことと同じく、連絡先・外部決済・性的な言葉を書けない（番付と管理人の詳細は、同意前の人も見るため）

- 実装コミット: `a317f96`、確認スクリプト: `ff18cfb`（origin/main）。作業フォルダ `.claude/worktrees/ranch-photo-icons`、ブランチ `release/ranch-cheers`（`origin/main` `b08eaf9` から、追跡先なし）
