# お貢ぎ牧場：既読無視・断れない請求・見えない限度額（2026-10-10）

## 対応内容

ユーザーの要望: 財布の契約数と、管理人の請求額（1回10,000 Pay まで）を引き上げる。「上限は財布が握る」は立場の弱いはずの財布が主導権を握る構図になり界隈に刺さらないため、「請求を払わなければ既読無視が続く」構図にする。

- 財布の発言に「既読」を出す。管理人が財布の発言を読んで返していない時、未払いの請求がある間だけ財布に「既読無視 ○時間／○日目」を出す（ユーザー決定）。管理人の発言か、ご褒美を添えた受け取りで終わる（請求は返事に数えない）
- 管理人の宣言「未払いは既読無視」（ユーザー決定）。カードの札で、掲示板・詳細・申し込み・財布募集の画像に出し、スレッドからも切り替えられる。進行中・申込中の契約へ写し、財布のスレッドに出す
- 請求は断れない（ユーザー決定）。「請求を断る」をなくし、払うか解約するかの二択。申し込みで「請求は断れず、払うか解約するか」の確認を必須にした（サーバーも `acceptNoDecline` を確かめる）。遊びの前提の文は改めたが版は上げない（上げると全員の確認が外れ、管理人が申し込みを受けられなくなるため）
- 限度額を本当に隠す（ユーザー決定）。限度額は `tributeContracts/{id}/private/limits`（財布だけが読める）へ移し、管理人の画面・スレッド・出来事・サーバーの応答・定型文に数字も変更も出さない。「財布が握る」の文言を外し、「上限」を「限度額」に改めた。下げても未払いの請求は残す（ユーザー決定）
- 数字（ユーザー決定）: 請求は1回10,000 Pay まで（財布の限度額に関係しない）、財布の契約は5件、管理人の進行中は50件、管理人の1日の受取上限は100,000 Pay。限度額の選択肢は1回〜10,000・1日〜30,000・合計〜100,000。1回3,000以上は Google で保護した財布だけ
- 追加案1〜4（ユーザー決定）: 払えない請求に「あと○Pay」とデイリーミッション・文字コラトレーニング・ルーレットの台本への近道、財布だけに「限度額が足りません（翌日から）」、直近30日に3,000 Pay 以上を請求した管理人の「高額請求」の札、管理人の契約数を30→50
- 財布募集の画像は、札が増えても型と称号を落とさず2段に並べ、その時は紹介を2行までにしてカードに収める
