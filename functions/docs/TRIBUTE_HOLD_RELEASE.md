# お貢ぎ牧場：お預けと願い出・抵抗する（2026-10-27）

## 対応内容

設計書14節の第2段（財布の打つ手）。

ユーザーの決定（2026-10-27）:

- お預けの既定は「受ける」
- 差し出された献上の突き返しは作らない

実装:

- お預けと願い出
  - 契約の設定「お預けを受ける」（`allowHolds`）。預ける側が申し込みとスレッドの「お預けの設定」（`set_holds`）で切り替える。
    - 申し込みの既定は「受ける」。
    - この設定より前の契約と、古い画面からの申し込みは受けない。
    - 受けないにすると、お預けと願い出はその場で消える。
  - 管理する側の「お預け」（`hold`、一言60文字まで）と「お預けを解く」（`unhold`）。期限はない。
    - お預けの間は、無言の献上ができない。
    - 請求に応える献上・管理口座の出し入れは、いつもどおりできる。
  - 預ける側の「願い出る」（`plea`）。
    - 金額は1回の限度額まで。超える時の数字は、預ける側にだけ返す。
    - 名目と一言を付けられる。願い出は1件ずつ。
    - 取り下げられる（`plea_withdraw`）。
    - 預ける側の発言に数える（既読無視の判定）。
  - 管理する側の「許す」（`plea_grant`）と「退ける」（`plea_deny`）。
    - どちらも一言を添えられ、管理人の返事に数える。
    - 許すと、預ける側はその金額と名目のまま、いつもの長押しで1回だけ差し出せる（`tribute` の `kind: "granted"`）。
    - 許した献上は、記録の上は無言の献上で `granted: true`。完了画面・スレッド・レシートに「願い出て許された献上」と出す。
  - 次の時、願い出（許したものも）は消える。
    - お預けが解けた時
    - 契約が終わった時
    - 性的な名目の許可を外した時（その名目の願い出）
- 抵抗する（`resist`）
  - 未払いの請求に、渋る一言（60文字まで、会話と同じ確認）を1件の請求に3回まで返せる。請求は断れず、未払いのまま残る。
  - 管理する側には「抵抗 2回」と出す。
  - 払うと、献上とレシートに回数（`resisted`）が残り、「2回抵抗して献上」と出す。
  - 預ける側の発言に数える。
- 定型文
  - 管理する側に「追い込む」の場面を足した。
  - お預け（管理する側）・願い出・抵抗（預ける側）の一言の候補は、それぞれのシートにだけ出す。
- スレッドの上
  - お預けの欄: 預ける側には「願い出る」「願い出中」「許された献上」、管理する側には「願い出」（許す・退ける）と「お預けを解く」。
  - 回数: 「願い出 ○回 → 許された ○回」「抵抗のすえ献上 ○回」「お預け 可／お預け中」。
  - やること: 管理する側に「願い出」、預ける側に「許された献上」。
- 差し出された献上を後から突き返す仕組みは作っていない（ユーザー決定）。
