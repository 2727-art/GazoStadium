# お貢ぎ牧場：管理の型を5つに（2026-10-27）

## 対応内容

ユーザーの決定（2026-10-27）。財布側の note の分析（`functions/docs/TRIBUTE_WALLET_PSYCHOLOGY.md`）をもとにした。

- 管理の型を5つにした: 見透かす・管理する・煽る・甘やかす・突き放す（`insight`・`manage`・`tease`・`pamper`・`aloof`）。
  - カード編集では、型ごとに一言の説明を出す。
  - 管理人は1つか2つ選ぶ。3つ目は選べない。
  - 主と副（ギャップ）はカードで伝えない。カードには「見透かす・煽る」のように、一覧の順で並べて出す。
- それまでの3つ（罵倒・事務的・甘やかし、カードの `style`）を解除した。
  - 本番のデータは書き換えず、`style` を読まないことで解除した。
  - 選び直すまで、カードは掲示板に出たまま、型の札だけが出ない。
  - 管理人の画面とカード編集に、選び直しの案内を出す。通知は送らない。
  - 次の保存では、型を選ばないと保存できない。
  - 過去の契約とレシートに写した型は、もともとどの画面にも出していない。
- 掲示板を型で絞れるようにした。画面の上で絞り、「入場料0のみ」と重ねられる。
- 請求の一言の候補を見直した。
  - 名目ごとの一言の後に、管理人が選んだ型ごとの一言を紫の札で並べる。
  - どれも強さの札を持ち、契約の上限以下だけを出す。保留していた「請求の一言を強さで分けるか」もこれで片付いた。
  - 型ごとの一言は18個。どの型にも甘めの契約で使える一言を入れた。性的な言葉は使わない。
  - 決まりはテストで確かめる。
    - お願いや営業の形にしない。
    - 急かさない。
    - ♥ は使わず、♡ は文末だけ。
    - 短く。
- 財布側の心理のまとめ（`functions/docs/TRIBUTE_WALLET_PSYCHOLOGY.md`）を一緒にコミットした（非公開）。
