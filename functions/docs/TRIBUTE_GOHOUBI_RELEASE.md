# お貢ぎ牧場：管理人アイコン・受け取りとご褒美・請求の名目（2026-10-09）

## 対応内容

- 管理人アイコン: 管理人カードの印を、用意した12種の丸アイコン（`avatar` 1〜12。1〜6 はゆるめの絵、7〜12 は同じ6人の大人びた絵）か、従来のペルソナ名の1文字（`avatar` 0）から選べるようにした。画像のアップロードはない。印の色はアイコンの縁と掲示板のカードの色になる。掲示板・管理人の詳細・契約一覧・スレッド・献上レシート・番付に出し、どこでも中の人の札を並べる。契約・レシート・管理人番付はその時点のアイコン番号を写して持つ。範囲外の値は端のアイコンに寄せず文字の印に戻す（サーバーと画面で同じ判定）
- 献上完了の画面: 長押しで差し出した直後に、金額・宛先・名目・種類・日時・支払後の財布・何回目か・レシート番号を並べる。牧場の見た目で作り、実在の決済サービスの名前や画面には似せない（従来の財布とレシート印字の演出を置き換え）
- 受け取る: 財布から差し出した献上（請求に応えて・無言）は、管理人が「受け取る」まで受け取り待ち。Pay は動かさず、献上の記録と献上レシートに受け取り時刻を書く。1つの献上に1回、契約が進行中の間だけ。入場料と管理口座からの徴収は最初から受け取り済み
- ご褒美: 受け取る時に、言葉の強さごとに決まった短い一言を1つ添えられる（辛口: ご褒美♡・ふふ♡ご褒美♡・ざこ♡・それっぽっち？・次も持ってきな など）。財布の「言われたくない言葉」を含むものは出さない。押すのは毎回管理人で、システムからは出さない
- 請求の名目: 管理費・ご褒美代・罰金と、性的な名目（寸止め料・射精料・お漏らし罰金）。請求は管理人、無言の献上は財布が選ぶ。性的な名目は財布が契約で許した時だけ使え（既定は許さない）、許可は財布だけがいつでも変えられる。外すと性的な名目の未払いの請求はその場で無効になり、スレッドと回数の表示から消える。契約ごとに名目別の回数とご褒美の回数を出す
- 見本（localhost のみ）で、カードの保存、献上・請求・受け取り・名目の設定を画面の上だけで試せるようにした

- 実装コミット: `e6e20a4`、確認スクリプト: `ae3717f`（origin/main）

## 互換性と限界

- 本番の HTML は `Cache-Control: max-age=3600` のため、公開前に開いていた人は最大1時間ほど旧画面になりうる。旧画面でも献上・請求は使え、受け取り・名目の変更の記録は表示されないだけ。旧画面から管理人カードを保存するとアイコンは文字の印に戻る（新画面で選び直せる）
- 既存の契約は性的な名目を許していない状態から始まる。今回より前の財布からの献上は受け取り待ちと表示され、管理人があとから受け取れる（前のレシートは受け取り印が付かない）
- 性的な名目の許可を外した後も、財布本人だけが見る献上レシートの一覧には、その時の名目が残る
- アイコンの元画像は1つ約112pxのため、詳細画面の大きい表示（76px）は高解像度の画面でやや柔らかく見える
- 2人での本番・エミュレータ通しの操作、iPhone／Android 実機、Safari での確認は行っていない
