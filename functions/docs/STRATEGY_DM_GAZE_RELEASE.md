# 戦略型1on1：見つめるモード（2026-11-04）

## 対応内容

ユーザーの依頼: 戦略型1on1にも見つめるモードを入れる（スマホの全画面DMの公開後、実機で問題がないことを確かめたうえで）。

通常型1on1の見つめるモード（`NORMAL_DM_THREAD_DESIGN.md` §9）と同じ見た目（`velvet-battle.css` の `vb-gaze-*`）で、相手の1枚を画面いっぱいに出し、言葉と狙い・直近のチャット・その時の操作・入力欄を半透明で重ねる。通信・保存・Rules・Functions は変えていない。

- 開く：相手の1枚を「開いて採点」「タップして開く」で開いた時（••• の「相手の1枚を開いたら、見つめるモードで開く」がオンなら。端末に保存、最初はオン）。開いた後の相手の画像はスレッドで押せばいつでも（前の手も）。戦略型の1枚は伏せて届き、添付の音声はタップしないと鳴らせないので、届いた瞬間には開かない
- 見ながら採点：自分の採点待ちの1枚なら、点数のボタン（60〜100）・数値・ひとこと・「返す」と、点数帯と理性の減り方の1行。スライダー・ひとことの候補・「参りました」は「候補・参りました」からシートへ。入力の id はシートと同じで、下書きと送信は共通。見ながら採点している間、PC の右の列にはシートを出さない
- 画像だけ：タップで文字と操作を隠し、その間だけピンチ・ダブルタップで1〜4倍（拡大の計算は `normal-dm-gaze.mjs`）
- 閉じる：✕・Escape、その1枚の採点を返した時、次の1枚を貼る番に入った時、操作シートを開いた時、決着した時
- チャットが届いた時は重ねている吹き出しだけを差し替える。背の低い画面（高さ760px以下）では重ねるチャットを2件に
- 前の1枚を見ている時に採点待ちの1枚があれば「N手目の1枚を見て採点する」

- 実装コミット: `6fa6f44`（見つめるモード）、`a1575b6`（README と公開後の確認スクリプト）。PR [#41](https://github.com/2727-art/GazoStadium/pull/41) をマージし、main は `23a5425`
- 作業と公開は `origin/main`（`bb7cad5`）から切った作業フォルダ `.claude/worktrees/strategy-dm-thread`（`feature/strategy-dm-gaze`）で行った。設計は `STRATEGY_DM_THREAD_DESIGN.md` §16

## 公開前の検証

- エミュレータ（auth・database・firestore・functions）と2つのオリジンで2人対戦:
  - 相手が貼り、受け手が帯の「開いて採点」を押すと、見つめるモード（採点パネル付き）で開いた。シートは開かない
  - 見つめている間に相手がチャットを送ると、重ねた吹き出しだけが差し替わり、画像は同じ要素のままだった
  - 見つめるモードで85点とひとことを返すと、点数が記録された時点で自動で閉じ、スレッドに「85点 ちょっとだけ効いた」が出た
  - スレッドの相手の画像（前の1枚）を押すと見つめるモードで開き、帯には相手の様子が出た。相手が権利を見送って自分の番になると閉じた
  - 反対側でも「開いて採点」で開き、Escape で閉じてから、今まで通りシートで採点できた
  - 降参で決着し、両者の結果画面まで進んだ（サイトの見出しも戻った）。コンソールのエラーは、新しい利用者で予想される `matchAchievementShowcase` の 400 だけ

## 互換性と限界

- 見た目だけの変更で、通信の形は変えていないので、公開前に開いていたページ（最大1時間キャッシュ）とも対戦できる
