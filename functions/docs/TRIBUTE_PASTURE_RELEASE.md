# お貢ぎ牧場：牧場経営 第1段「わたしの牧場」（2026-10-28）

## 対応内容

設計書16節の第1段。ユーザーの決定（2026-10-28）:

- ねらい: 管理人は1on1に興味がなく、財布とやり取りするためにしか覗きに来ない。財布管理のほかに、牧場を眺める・育てる楽しみを足す。
- 牧場レベルは関係の積み重ねで上げ、額では上げない。
- 放牧は財布の同意（契約ごと）。見られるのは管理人と本人だけ（本人が見る画面は第2段）。
- 吹き出しは語り手の事実（財布が書く鳴き声は第2段）。
- 絵は Blender で、やわらかい箱庭の絵柄（「どうぶつの森のようなタッチ」。特定のゲームの絵・キャラクターはまねない）。
- 置き場所は管理人の「契約」画面のいちばん上。
- おすすめの決め方をすべて採用した:
  - 放牧は新しい申し込みで既定オン、古い契約はオフ。
  - 途中からの管理人は、迎えた財布の数 × 5 から始める。
  - 動物は牛・豚・羊を管理人が選ぶ。
  - 段階の分け方は設計書16.11のとおり。

入ったもの:

- わたしの牧場（管理人カードを作った人だけ）
  - 放牧に同意した進行中の契約の財布が、牛・豚・羊になって芝の島を歩く。
  - 空と光は日本時間で朝・昼・夕方・夜に変わる（夜は星・月・窓の灯り）。
  - 動物のしぐさと語り手の一言は、契約の今の状態だけで決める（三人称の事実。財布の言葉として作らない）。
    - 今日献上した: 干し草を食べる
    - 受け取り待ち: 手紙が浮かぶ
    - お預け中: 杭につながれる
    - 願い出中: 柵のそば
    - 未払い: そわそわ歩く
    - 出稼ぎ中: 牧場にいない（「出稼ぎに出ている：○○」）
    - 23〜6時: 眠る
    - 3日なにもない: 柵の外を見る
  - 吹き出しは1頭ずつ順に出る。
  - 動物を押すと、名前・ようす・動物を選ぶ（牛・豚・羊）・「スレッドへ」が出る。
  - 日報: 前に見た時からの出来事を5行まで。前に見た時の数は、その端末にだけ残す。
  - 動きを減らす設定では止める。来ないと減る・弱る仕組み、通知、連続日数は入れていない。
- 牧場レベル（Lv1〜10）
  - 経験値は、財布を迎える5・仕えた日3・受取印1・出稼ぎや復唱の確認2・願い出への返事1・延長2。
  - 組ごとに1日10まで。下がらない。Pay の額は使わない。
  - 公開より前から続けている管理人は、迎えた財布の数 × 5 から始まる。
  - レベルで施設が増える（柵・水飲み場・小屋・花畑・風車・池・納屋・時計台・金の牛の像）。
  - 管理人カードの札「牧 Lv.○」（掲示板・管理人の詳細・自分のカード）。
- 財布の同意
  - 申し込みの「牧場に放牧される」。
  - スレッドの「牧場の設定」で切り替えられる（出来事 `grazing_changed`）。外すと、その場で牧場からいなくなる。
- 絵: `assets/tribute-ranch/` に84枚の WebP。
  - 背景10段階・動物3種 × しぐさ5つ・小物3つを、昼・夕方・夜で描いた。
  - 合わせて約740KB。1回に読むのは約70KB。
  - 描くスクリプト `art/tribute-ranch/render_ranch.py` は公開しない（`firebase.json` と `.assetsignore` の両方で除外）。
- 見本: `?tributePreview=ranch`（Lv10）と `hub`（Lv5）に、放牧された5頭。

実装で決めたこと:

- 動物は、建物とくらべて少し小さく出す（絵の幅の17%）。スマホでは牧場の絵が幅290pxほどで、本来の大きさだと重なりすぎたため。
- 続けて置く動物どうしが離れるように、立ち位置の順番を並べた。
- 管理人が動物を選んでも、出来事は残さない（管理人の牧場の見た目だけの操作）。
