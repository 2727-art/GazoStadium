# お貢ぎ牧場：牧場の実績（遊び方の型とシークレット、2026-10-30）

## 対応内容

ほかのモードと同じく、遊び方の傾向で解除される実績を、お貢ぎ牧場に足した。設計書は17。

ユーザーが決めたこと（2026-10-30）:

- 実績名は、こちらの提案どおり（「実績名は提案通りでOKです」）。
- 枠は系統ごとに作り、レベルが上がるほど豪華にする。冠で豪華さを出すのではない（「実績枠は全て共通ではなく、実績系統に応じた枠が理想です。「豪華＝冠」ではありません。」）。
- 数え方と実績一覧への登録に進む（「数える仕組み・実績一覧への登録に進んでください」）。
- 提案の線を守る:
  - 額では解除しない。連続日数・毎日・期限つきは作らない。
  - 自動では公開しない。
  - 同じ組とは日本時間の1日1回だけ数える。
  - これまでの記録は、確かめられるものだけ数え直す。

### 実績

- 管理人の型が11系統、財布の型が11系統（今の2つの記録とは別）。
  - 段階は5つ（1・3・10・30・100回）。
  - 牧場レベルとなつきは4段階、なでる・なでられたは5段階の節目。
- シークレット7つ（財布4・管理人3）。条件は解除するまで隠す。
- 牧場の実績は、今の2つの記録（各10段階）と合わせて135個。

### 数え方（`tributeAction` と共通の実績の一覧）

- 牧場の操作の中で数える。
  - 組の `achievementDays` で、同じ組とは日本時間の1日1回まで数える。
  - 数えるのは進行中の契約だけ。
- 増えた数は、その操作の書き込みの直前にまとめて読み（実績の記録と実績の一覧）、1回だけ書いて、その場で解除する（`stageAchievements`）。
- 迎えた財布の数・牧場レベル・仕えた日は、いちばん大きくなった値を残す。
- 既読無視は、管理人がまだ返していない財布のメッセージまで読んだ時に数える。
- 「気分次第」は、許した日と退けた日が同じ日になった時。「二度目の願い出」は、同じお預けの間に、退けられたあと許された時。
- 「名付け親」は、名前の保存と同じ書き込みで解除する。
- これまでの記録は、初めて使う時に1回だけ数え直す（`historyVersion` 2）。対象は次の6つで、ほかは公開した時から数える。
  - 迎えた財布の数・牧場レベル・なでた日・なでてもらった日・貢ぎオセロの勝ち・いちばん長く仕えた日
- 共通の実績の関数（`functions/index.js`）は、版2の数え直しが済むまで、牧場の分を先に書かない。

### 画面

- 牧場の「牧場の実績」の欄を、管理人の型・財布の型・シークレットの3つに分けた。
  - 系統ごとに、枠・いまの名前・段階・数を出す。
  - 見つけていないシークレットは、灰色の封蝋「？？？」にする。
- 枠は24系統それぞれの形と飾り。
  - 段階が上がるほど、飾りが増える。縁は 木・革 → 銅 → 銀 → 金 → 金と光 の順に変わる。
  - シークレットは、それぞれ色の違う封蝋。
- 管理人カードの実績（牧場の分）にも、小さな枠を出す。
- 実績一覧に「お貢ぎ牧場・管理人の型」「お貢ぎ牧場・財布の型」「お貢ぎ牧場・シークレット」を足した。
- どの牧場の操作でも、解除した実績は共通の演出で1回だけ知らせる。
- 見本は `?tributePreview=achievement-frames`。
