# お貢ぎ牧場：言葉の献上と復唱・管理人の自分の言葉・延長（2026-10-27）

## 対応内容

設計書14節の第3段（財布の打つ手と管理人の言葉）。

- 言葉の献上（`offer_words`、預ける側）
  - 400文字までの文を差し出す。Pay は動かない。
  - 1つの契約で日本時間の1日3回まで。確認は会話と同じ。
  - 管理する側は献上と同じく「受け取る」（`receive`、受取印とご褒美）。受け取り待ちの数に入る。
  - レシートは出さない。番付・貢がれ総額・応援欄・実績・限度額には数えない。
- 復唱（`recite_order`・`recite`・`recite_withdraw`・`recite_confirm`）
  - 管理する側が、言わせたい一言（60文字まで）と回数（1／3／5回）を送る。1つの契約に1件まで。
    - 請求の一言と同じ確認と、言われたくない言葉の確認をする。
    - 性的な言葉は、性的な名目を許した契約でだけ。
  - 預ける側は一字一句同じに打つ。サーバーが確かめる（NFKC、前後の空白を取り、続く空白を1つにする）。
  - 回数に届くと、管理する側が受取印とご褒美で「確認する」。
  - 復唱しなくても何も起きない（既読無視に数えない）。ご褒美を添えた確認は既読無視を終える。
- 管理人の自分の言葉（`set_own_words`）
  - 自分の定型文（10個まで・各60文字）とご褒美（5個まで・各12文字）を、強さの札（甘め・普通・辛口）付きで登録する。
  - 管理人だけが読み、カードと掲示板には出ない。
  - 候補に出すのは、次をすべて満たすものだけ（サーバーもご褒美を同じ条件で確かめる）:
    - 強さの札が契約の上限以下
    - 言われたくない言葉を含まない
    - 性的な言葉を含むなら、性的な名目を許した契約
- 受取印の言葉
  - 7文字までの自分の言葉を、一覧の印と合わせて3つまで受取印にできる。
  - カードの `seals` に `word:言葉` で入れる。レシートと貢ぎ報告の画像にも残る。
  - 今日のひとことと同じ禁止表現と、性的な言葉を通さない。
- 延長（`extend_request`・`extend_withdraw`・`extend_accept`・`extend_decline`）
  - 預ける側だけが日数（1／3／7／14／30日）を選んで申し込む。
  - 管理する側が受けると、いまの期限から延びる。断ることもできる。
  - 入場料は取らない。申し込みは1件ずつ。
