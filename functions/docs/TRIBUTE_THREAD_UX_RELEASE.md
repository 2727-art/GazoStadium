# お貢ぎ牧場：スレッドの使い勝手（2026-10-26）

## 対応内容

利用者（スレッドで長く会話する管理人）の要望4つを、ユーザーの決定で1回の公開にまとめた。

1. スクショで「名無しの財布」や財布の額を隠し、やりとりをたくさん載せたい → 「スクショ表示」
2. 財布の発言を見ながら打ちたい（入力欄を会話の真下に） → 入力欄を会話のすぐ下へ
3. 「名無しの財布」ばかりで見分けがつかない → 管理人だけに見える呼び名と、財布名の説明の直し
4. 請求を送ったタイミングで、タイムラインにも印がほしい → 未払いの請求の印

- 入力欄: 会話 → 入力欄 → 操作（請求する・管理口座から徴収・報告を求める・通報など）の順にした
- 未払いの請求の印: 本体は上の「未払いの請求」に出したまま、タイムラインの送った時点に「請」の印・金額・名目・未払い・一言の小さな行を残す。払われると、ふつうの請求の行に変わる
- 呼び名（ユーザー決定: 管理人だけに見える）: スレッドの名前の横の「呼び名を付ける」から12文字まで。管理人の記録 `tributeProfiles/{uid}.payerNicknames`（財布の UID ごと、サーバーだけが読む）に置く（`set_nickname`、管理人だけ）。契約の一覧・スレッドの題と出来事・やること・「次へ」で財布名の代わりに出し、同じ財布との次の契約にも引き継ぐ。契約の記録には書かないので、財布からは読めず、一覧の並びも変わらない
- 財布名の説明: 自分の設定の欄を「管理人のスレッドと番付に出ます」に（以前は「番付に載る時だけ使います」）。申し込みでも、空のままだと「名無しの財布」になり見分けにくくなることを出す
- スクショ表示（ユーザー決定: 管理人は「スクショ掲載 可」の契約だけ、財布は常に）: 見出し（相手の名前・自分の財布の額）・移動・サイトの見出しと足元・相手の札と限度額・未払いの請求・操作・入力欄・会話の中のボタンを隠し、会話だけを出す。右下の「スクショ表示を終える」で戻る。見た目だけで、掲載の許可の代わりにはならない

- 実装コミット: `f9d4990`、確認スクリプト: `24afefe`（origin/main）。作業フォルダ `.claude/worktrees/ranch-photo-icons`、ブランチ `release/ranch-thread-ux`（`origin/main` `8a468b9` から、追跡先なし）
