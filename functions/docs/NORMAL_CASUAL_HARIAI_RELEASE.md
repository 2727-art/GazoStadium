# 通常1on1 気軽な貼り合い要素の追加（2026-09-30）

## 対応内容

通常1on1は「サクっと貼り合いたいプレイヤー向け」のモードとして、同時に1枚を選んで同時に採点する流れと勝敗計算を変えずに、貼り合いの要素を薄く足した。ユーザー判断により、10点での連投は見送り、カードのひとことは自由記述も許可し、既存の口調セットは女の子なりきり系へ置き換えた。

- 実装コミット: `6625f50`（origin/main）
- 口調セット: 王道主人公〜推し活の7種を削除し、戦略型と同じ6種（つよつよ・よわよわ・小悪魔・お姉さん・甘えんぼ・清楚）に置き換えた。旧セットの定型を保存していた場合は新しい既定（つよつよ）へ移し、自由記述は保持する。旧画面の相手から届いた旧定型は自由記述として扱わない
- カードのひとこと: 各画像に任意で30文字まで。定型候補または自由記述。画像と一緒にP2Pで送り、Firebaseへは保存しない。受け手が自由記述を非表示にしている場合は、送信者の口調セットの定型へ置き換えて注記する
- 採点のひとことリアクション: 点数帯（1〜6／7〜8／9〜10）と自分の口調に合わせた候補から任意で1つ。両者の点数が確定した後にだけP2Pで送り、受け手は実際の点数と点数帯が一致する時だけ表示する
- 採点ログ: 画像選択画面に、過去ラウンドで自分が出したカードと双方の点数を表示する。相手の画像はラウンドごとに解放する従来の扱いを変えず、ログには残さない

## 配信対象

- Hosting のみ: `online.js`、`finish-roleplay.mjs`、`velvet-battle.css`、`styles.css`、`index.html`（キャッシュキー）
- Functions、Realtime Database Rules、Firestore は対象外。勝敗・RATE・報酬の計算とサーバー検証は変更していない

## 本番反映結果

- `6625f50` を origin/main へ push した直後に Hosting を公開した（workers.dev 経路は push で自動再ビルドされるため）
- web.app・firebaseapp.com・anjugames.workers.dev の3経路で、`index.html`・`online.js`・`finish-roleplay.mjs`・`velvet-battle.css`・`styles.css` が手元と一致した（改行コードを揃えて比較）。`README.md`・`STRATEGY_HARIAI_DESIGN.md`・`functions/docs/` 配下は3経路とも 404。workers.dev は再ビルド待ちの1回目だけ旧版で、15秒後の2回目に24項目すべて一致した
- 内蔵ブラウザで本番トップを表示し、新しい4ファイルが 200 で読み込まれることを確認した。コンソールのエラーは、内蔵ブラウザで App Check（reCAPTCHA）の交換が 403 になることと、それに伴う公開統計2関数の 401 だけで、今回の変更とは無関係
- 本番では通常1on1の画面を開かず、実対戦も行っていない（匿名アカウント作成と本番戦績への記録を避けるため）

## 互換性と限界

- 本番の HTML は `Cache-Control: max-age=3600` のため、公開前に開いていた人は最大1時間ほど旧画面のままになりうる。旧画面は新しいメッセージ（`score-reaction`）と画像の追加項目（`caption`・`voiceSetId`）を無視するだけで、対戦は通常どおり進む。ひとことと反応が表示されないだけ
- iPhone／Android 実機、Safari での確認は行っていない
- 本番の認証付き環境での2人対戦は行っていない
