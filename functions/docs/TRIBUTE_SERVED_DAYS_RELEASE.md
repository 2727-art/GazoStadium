# お貢ぎ牧場：仕えた日数の番付と応援欄の並び（2026-10-28）

## 対応内容

設計書15節の第1段（15.1）。ユーザーの決定（2026-10-28）。

財布側と管理人側の note の分析では、財布どうしを献上額で比べると逆効果になり得る。

- 財布が自分で引いた線を崩す。
- 財布が求める1対1の関係を薄める。
- 「他の財布と比べる」「えこひいきだ」という、管理人の負担の火種になる。

そこで、管理人ごとの番付と応援欄から「額の比較」を外した。

- 管理人ごとの番付
  - 当月は、仕えた日数の順。その管理人に献上か言葉の献上をした日本時間の日の数を、1日1回まで数える。同じ日数なら首輪番号の古い順。
  - 累計は、首輪番号の古い順（長く仕えている順）。
  - 財布どうしには、日数と首輪番号だけを見せ、額は出さない。
- 献上額の順位（当月・累計）は、管理人本人が自分の詳細を開いた時にだけ「献上額の順位（あなただけに見えます）」として出す。
- 応援欄は、書いた・書き直した時刻の新しい順にした。それまでは今月の献上額の順で、額は出していなくても並び順で分かっていた。見出しは「今月貢いだ財布だけ・新しい順」。
- 仕えた日数は、組（`tributePairs`）の `servedDays`・`servedMonthKey`・`servedDayKey` に数える。
  - 月は、貢ぎ帳の `monthKey` と分けて持つ。言葉の献上だけの月に `monthKey` を進めると、月の額と、貢がれ総額の財布の人数がずれるため。
  - 数え始めは公開した日から。10月は途中から数える。
- インデックスを3つ足した。インデックスを作っている間は、次のように扱う。
  - 番付は、その欄だけ空にする（詳細は開ける）。
  - 応援欄は、前のインデックスで読んで時刻で並べ替える。
- 管理人番付・貢がれ総額・ハートの札は変えていない。
