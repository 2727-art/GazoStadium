## 4. お金が持つ意味

- **お金に意味をつけてもらう。** 本人は、必需品以外を「無駄」として自分にご褒美を与えずに生きてきた。貢ぐと、相手がそのお金に意味をつけてくれる（#32）。
- **献身の一つの形。** 根っこは「尽くしたい」「相手の笑顔が見たい」で、送金はその表れ方の一つ、と整理している（#44）。
- **存在を認めてもらう。** 心を動かされたのは「存在する意味をくれる」構文だった（#9）。届かない相手に自分を刻む行為、という見方もある（#77 AI）。
- **財布として扱われる。** 甘い言葉の裏に「財布を持って来て」が省かれていると分かっていて、それでも乗る（#14）。小説では「ATM」と呼ばれる（#46）。
- **責任を外に出す。** 「貢がされてしまった」という形にする（#51 創作）。
- **後期は自分の選択として。** 貢ぐなら自分で選んだこととして、という立場に移る（#77 AI）。

## 6. 好む相手・嫌う相手

### 好む型（多い順）

1. **見透かす（知的・冷静）。** 敬語で淡々と事実を言い当てる。いちばん多く（約15本、小説の色摩凛など）、反応もいちばん強い。理想の貢がせ嬢を「知的・冷徹・カリスマ」と書く（#9）。高嶺の花として憧れと畏れが混じる人物像も、この近く（R-18「敗北と身体支配」）。
2. **管理する（規律・報告・独占）。** 遅刻への罰、収支報告の監査、約束の取り立て、ほかの相手に貢いだことを咎める。効率よく貢がせる手段として明言している（約7本）。
3. **煽る（小悪魔・年下）。** ♡付きの甘い声で笑い、「ざこ」と突き放し、払うとまた甘くなる。作者の小説の語り手（「あえちゃん」）もこの型で、甘えた声で絞るか、強く命令して絞るかを選ばせる（約7本と R-18 の多く）。
4. **甘やかす（肯定・感謝させる）。** 「貢ぐのは悪くない」と肯定し、礼を言わせる。実生活で本当にお金が動いたのは、この型の一言（約6本、#9、#14）。
5. **突き放す（無関心・届かない）。** 届かない相手に認められたい、相手はこちらを気にしていないのに自分から戻ってしまう（3〜4本、#24、#77）。

  - 本人は手を汚さず、男が勝手に落ちていく。

## 12. 牧場への示唆

すでに入れたもの（設計書14節、2026-10-27）:

| 財布の心理 | 牧場の仕組み |
|---|---|
| 抵抗しきってから屈するのが濃い | 抵抗する（請求に3回まで渋れる） |
| 許可をもらって差し出したい | お預けと願い出 |
| 合図になる一言、言われたい言葉 | 言われたい言葉（財布が登録し、管理人が見る） |
| 復唱させられたい | 復唱（一字一句同じに打つ） |
| 決まり文句・営業は醒める | 管理人の自分の言葉、募集を「受付」に寄せる |
| お金に意味をつけてほしい | 名目、ご褒美、受取印、レシート |
| 覚えていてもらいたい | 首輪番号、管理人だけが付ける呼び名 |
| 返事のタイミングを相手が握る | 既読・既読無視（返事は毎回人が押す） |
| 自分で引いた線は効く | 財布だけが決める限度額（1回・1日・合計）、強さの上限 |
| 記録は効く | 貢ぎ帳、レシート |

守っている線:

- 現実のお金は使わない（換金できない AnjuPay だけ）。借金や生活費に届かない。
- 集団で貢ぐ目標や企画、過去の献上を管理人が見せて思い出させる仕組みは作らない。
- 支払いをせかす通知は作らない。
- 外部の決済・連絡先・個人情報・脅しの言葉は止める。

まだのもの・検討の種:

- **管理の型。** いまの3つ（罵倒・事務的・甘やかし）には、いちばん好まれる「見透かす」や、「管理する」「煽る」「突き放す」が入っていない。好まれるのは「核は一貫、表面は切り替え」。言葉の強さ（財布が決める上限）とも重なっている。
- **見透かされたい。** 管理人が財布を「言い当てる」材料（財布が自分から出す情報）。ただし個人情報を求めない線は守る。
- **衝動と支払いの間に時間を置く。** お預けと願い出は、それに近い。
- **効き目は約10日。** 契約の期間や延長の区切りとの相性。
- **自分で線を引く助け。** 財布が自分で見る、月ごとの貢ぎ暦（以前の候補）。
