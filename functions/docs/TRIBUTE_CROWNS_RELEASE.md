# お貢ぎ牧場：番付の冠と月替わり（2026-10-31）

## 対応内容

設計書18節。ユーザーとのやりとり（2026-10-31）:

- 最初の相談は、牧場で確率で毎日生産物が出て、売ると Pay になり、番付の成績で質と数が変わる案だった。
  - ログインボーナス・確率・新しい Pay の発行・番付のための煽りにあたるので、形を変える案を出した。
  - ユーザーは「生産物売却でPAY獲得はなくしましょう」と決めた。
- 次の案（前月の上位5名が、翌月に財布とのスレッドに画像を出せる）は、保存も P2P も見送った。
  - ユーザーの理由: 保存すると、貼り合いスタジアム自体の仕組みを疑われる恐れがある。
- ユーザーの見立て: 飾りと有料アイコンは誰も買っていない。金庫は使われるが、金庫の飾りは使われていない。上位は争っていて、「1位の管理人」と自慢する管理人がいた。
  - 私の読み: 管理人が見せたいのは、買った見た目ではなく貢がれている証拠。月が変わると番付が0に戻り、自慢を残す場所がない。
- 出した案の1・2・3を、ユーザーが選んだ: 「１，２，３を一緒に入れます。画像P2Pの案は見送ります。」

入ったもの:

- 月の締め
  - 月が変わって10分たってから、最初に掲示板・番付・管理人の詳細・牧場の順位を開いた時に、前の月を1回だけ締める（`tributeHallOfFame/{monthKey}`）。
  - 2つの番付の上位10を、締めた時の名前・アイコン・印の色・中の人の札ごと残す。
  - 10位以内の管理人のプロフィールに、その月の順位を残す（`monthRanks`）。
  - 冠の順位は、どちらの番付も財布3人以上から貢がれた管理人だけで数える。番付加算の画面には人数の条件がないので、画面の順位と冠の順位が違うことがある。
- 歴代の冠
  - 各番付の1〜5位が冠になり、消えない。
  - 掲示板のカードの札は、先月の冠があれば「先月 首位」など、なければいちばん良い冠と回数（「冠 首位×3」）。
  - 管理人の詳細に「歴代の冠」の一覧。
  - 番付に「殿堂」タブ（締めた月ごとに2つの番付の1〜3位、直近12か月、締めた時の額と財布の人数）。
- 先月の首位の特権（翌月の1か月）
  - 掲示板のいちばん上に「先月の首位」の欄。金の帯と、番付のひとことを勝ち名乗りとして出す。下の一覧には重ねない。
    - ふだん掲示板に載る条件（受付中・直近7日に動いた・隠されていない・見る人がブロックしていない・絞り込み）を満たす時だけ。
  - 先月の1〜5位は、受付カードの上の辺に「10月 貢がれ総額 首位」のような金の帯が入る。
- 月替わりの結果発表と収穫の棚
  - 月が変わって初めて「わたしの牧場」を開いた時に1回だけ、先月の結果（2つの番付の順位・取った冠・今月の特権・収穫）を出す。
    - 出したことはその端末に残す（別の端末では、もう一度出る）。
    - 先月、財布から1度も貢がれていない管理人には出さない。
  - 収穫の棚: 首位は金の卵、2〜3位は銀の卵、4〜10位は大きな卵、番付の外でも貢がれた月は牛乳。Pay も確率もない。
  - 日報に今月の順位の動き（「番付加算で○○に抜かれて4位になった」など）。通知はしない。
  - 収穫の絵4枚は `art/tribute-ranch/render_ranch.py` で昼の光だけ描いた（`harvest-{gold|silver|egg|milk}.webp`）。
- 操作: `ranch_standing`（管理人）と、`rankings` の `kind: "hall"`。
