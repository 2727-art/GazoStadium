# お貢ぎ牧場：契約までの導線を短くする（2026-10-26）

## 対応内容

利用者（管理人）の要望: 貼り合いはせずお貢ぎ牧場がメインなので、「トップ→スクロール→お貢ぎ牧場→スクロール→管理している契約を確認」は手間がかかる。トップでタブを管理できるようにするなど、動線を楽にしてほしい。

Codex の案（契約一覧を先頭に・設定をまとめる・管理/預けるの切り替え）に、トップの近道は牧場を使っている端末だけに出す・やることの1行・直接開くURL・スレッドの「次へ」を足し、ユーザーの「おすすめの順番で進めてください」で、3段とも1回の公開にした。

1. 契約の画面
   - 契約のある人は「やること → 契約の一覧 → 自分の設定」の順。契約がまだない人は、自分の設定（始め方）を先に出す
   - やること: 申し込み・未払いの請求・受け取り待ち・使用許可の申請・残高報告の依頼・未読を種類ごとの数で出し、押すとその種類の最初の契約を開く。掲示板から外れそうな時の知らせもここに出す
   - 管理と財布の両方の契約がある人は「管理している／預けている」を切り替え、選んだ方を端末に覚える（`hariai.tribute.hubRole.v1`）
   - 財布の始め方は、管理人カードも契約もない人にだけ出す
2. トップの近道と直接開くURL
   - 管理人カードか契約がある端末にだけ、トップの一番上に「お貢ぎ牧場 契約を開く」を出す（牧場の状態を読んだ時に `localStorage` の `hariai.ranch.regular.v1` を残し、トップはそれだけを見る。サーバーには聞かない）。はじめての人のトップは1on1の入口から始まるまま
   - `?open=ranch` で契約の画面を直接開く。牧場にいる間は URL にこの印を付け、トップへ戻る時に外す。自分の設定に、いま開いている場所の URL のコピー欄を置いた（場所が変わると別の匿名アカウントになるため、正規の URL には寄せない）
3. スレッドの「次へ」: 一覧の並びで、いま開いている契約の次から、やることのある契約を開く。スレッドで変わったやることは一覧の行にも写す

あわせて直したもの:
- トップの「お貢ぎ牧場の番付」の説明が「今月の財布の人数で並ぶ管理人」のままだった（番付加算の順に変えた 2026-10-24 の公開の取り残し）。「今月の番付加算で並ぶ管理人」にした
- 契約一覧で、管理人の進行中の契約に「終了」と出ていた。限度額は財布にしか見えず、管理人の行には限度額がないため、終わった契約の表示に落ちていた。「今日 ○Pay ・ 合計 ○Pay」を出すようにした

## 互換性と限界

- トップの近道は、公開後にその端末で一度お貢ぎ牧場を開いてから出る（それまでの端末には印がない）
