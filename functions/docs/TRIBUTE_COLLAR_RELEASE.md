# お貢ぎ牧場：受取印・首輪番号・貢ぎ報告の画像・界隈の定型文（2026-10-09）

## 対応内容

- 受取印: 管理人カードに、決まった一覧（確認済・受領・よくできました・合格・雑魚・養分・ご苦労）から3つまで登録する（既定は受領・よくできました・確認済、自由入力なし）。受け取る時に1つ選んで押し、日付印の形（上段に印の言葉・中段に日付・下段に管理人名）で献上の記録と献上レシートに残る。登録していない印は登録の1つ目に、財布の「言われたくない言葉」に当たる印は「受領」に置き換える
- 首輪番号: 受理した時に管理人ごとに初めての組へ1号から順に振る（「ミオ様の財布 3号」）。再契約でも組の番号を使い、使い回さない。スレッド・契約一覧・献上レシート・画像に出す。番号のない進行中の契約は次の献上で振る
- 既読・受け取り待ち: 管理人がその献上まで読んだのに受け取っていない時、財布側に出す（相手の既読位置を契約の表示に追加）
- 貢ぎ報告の画像（財布だけ・端末の中で作る）: 「このレシート」と「やりとりを切り抜く」（選んだ献上までの最大3回分を請求 → 献上（受取印）→ ご褒美で並べ、「寸止め料 10回 → ご褒美 3回」を見出しにする）の 1080×1350 PNG。名目・金額・受取印とご褒美は既定で入れ、財布名は既定で入れず「財布 3号」。管理人の名前・アイコン・請求の一言は、管理人がカードの「貢ぎ報告に出してよい」にしている時だけ入れ（決めていないカードは「管理人様」とシルエット）、許可は画像を作る時に読み取り専用の `share_info` で確かめる。会話の文と URL は入れず、「AnjuPay・換金不可・アプリ内ポイント」を必ず入れる。スマホは共有シート（画像と「#貢ぎ報告 #お貢ぎ牧場」）、それ以外は保存
- 定型文: 辛口に ATM・養分・お財布くん・家畜などの言葉を足した。首輪番号の入る文は番号のある契約でだけ、寸止め・射精管理の文は性的な名目を許した契約でだけ出す。請求の一言に名目ごとの候補を出す
- 画面が隠れている間に `img.decode()` が終わらず画像作りが止まる問題を、`load` を待って4秒で打ち切る形にして避けた

## 互換性と限界

- 本番の HTML は `Cache-Control: max-age=3600` のため、公開前に開いていた人は最大1時間ほど旧画面になりうる。旧画面からの受け取りは印を選べず、登録の1つ目（未登録なら受領）で押される。旧画面から管理人カードを保存すると、受取印は既定の3つ、貢ぎ報告の許可は「出さない」になる（新画面で選び直せる）
- この設定より前の管理人カードは、管理人が許可を付けるまで画像では「管理人様」。既存の進行中の契約は次の献上で首輪番号が付く
- 共有シートで画像ごと送れるかは端末とブラウザによる（対応しない時は保存して案内を出す）
- 2人での本番・エミュレータ通しの操作、iPhone／Android 実機・Safari での共有シートと画像の確認は行っていない
