# お貢ぎ牧場：貢ぎオセロ（2026-10-28）

## 対応内容

設計書15節の第2段（15.2）。ユーザーの決定（2026-10-28）:

- 財布は契約で受けるかを選ぶ。その範囲の中で、始めるかどうかは管理人だけが決める。
- 財布は降参できる。設定を外すと、進行中の対局は罰金なしで終わる。
- 仕掛けは、おすすめの9つをすべて入れる:
  - コインの石とひっくり返し
  - 石の差 × 1枚の額の罰金
  - ハンデ
  - 型ごとの一手の一言
  - 降参
  - 負けた後の復唱
  - 戦績と連敗
  - 決着の画像
  - 手番の期限なし

入ったもの:

- 同意:
  - 申し込み画面に「貢ぎオセロを受ける」（`allowOthello`）を足した。新しい申し込みは既定で「受ける」。
  - それまでの契約と古い画面からの申し込みは「受けない」として扱う。
  - 財布はスレッドの「貢ぎオセロの設定」でいつでも切り替えられる。
- 始める（管理人だけ）:
  - 1枚あたりの額（1／5／10 Pay）を選ぶ。
  - ハンデ（なし／管理人が角を1つ持って始める／財布に角を1つあげる）を選ぶ。
  - 先手を選ぶ。
  - 一度に1局。前の罰金が払われるまで次は始められない。
- 対局:
  - サーバーが一手ごとに確かめる。打てない側は自動でパスし、両方とも打てなければ終局。
  - 手番の期限はない。止まった対局は、管理人が罰金なしで終わらせられる。
  - 一手に一言（60文字、会話と同じ確認）を添えられる。添えた手は会話として数える（既読無視の判定）。
  - 管理人には、場面（角を取った・ひっくり返した・財布がパスした・終局）ごとの一言の候補が出る。
    - 候補は、型（5つ＋型なし）× 強さ（甘め・普通・辛口）で、契約の上限まで。
    - 性的な言葉と「ください」「お願い」は使っていない。♡は文末だけ。
- 決着:
  - 罰金は、石の差 × 1枚の額。降参は、その時の差と1枚分の大きい方。
  - 自動では引き落とさない。財布が長押しで差し出す。
    - 上限は財布の1回の限度額。超える時は、財布の画面にだけ「限度額まで」と出す。
    - 記録の上は献上（名目は罰金）で、`othello` の印が付く。種類の表示は「貢ぎオセロの罰金」。
  - 払われない時は、管理人が同じ額の請求を1回の操作で出せる。請求は断れない決まりのまま、抵抗はできる。
  - 管理人の決着の欄に「復唱させる」を置いた（既存の復唱）。
  - 財布は、決着の画像（最後の盤面・差・罰金・戦績）を保存できる。選べるのは「金額」「財布名」だけ。URL は入らない。
- 戦績:
  - 組ごと（契約をまたぐ）に「通算○戦○敗（○連敗中）」を数え、スレッドの上と対局の欄に出す。
  - 財布どうしでは比べない（番付には出さない）。
- やること: 「オセロの手番」（手番の側）と「オセロの罰金」（財布）を足した。
- 見本（`?tributePreview=thread-manager`・`thread-payer`）:
  - 管理人の見本は、自分の手番の対局。打つと相手の手もその場で打ち、パスと終局まで進む。
  - 財布の見本は、差し出す罰金と決着の画像。
