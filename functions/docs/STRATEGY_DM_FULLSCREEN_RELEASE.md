# 戦略型1on1：スマホの対戦を全画面のDMに（2026-11-04）

## 対応内容

ユーザーの報告: Android の Chrome での戦略型1on1のプレイ画面で、表示範囲が非常に狭く、画像やチャットの快適性が犠牲になっている（スクリーンショット2枚）。改善案（全画面DM・ヘッダー1段・帯を1行・画像を大きく）のうち1〜4を作ることになった。

幅360・高さ674px（アドレスバーが出ている時とほぼ同じ）で測ると、相手の番のスレッドは193px（画面の29%）、自分の番でシートを開くと44pxだった。上から、サイトの見出し72px・「〇〇との交流」の欄93px・DMヘッダー143px・段階の帯85px・入力欄64px。DMの高さを「画面の高さ − 上の部分」で決めていたため、ページを少しスクロールすると、その分だけ入力欄の下が空いた（報告の1枚目）。

スマホ・タブレット（900px以下）の対戦中だけ、次のようにした。PC（901px以上）は変えていない。

- サイトの見出しと「〇〇との交流」の欄を出さず、DM を画面の高さいっぱいに置く。ページはスクロールしない
- ••• に「〇〇との交流」の欄（ブロックして退出・退出する）、安心設定、効果音のスイッチ（見出しの SE ボタンと連動）を置く。ブロックまでは2タップになる（ユーザー了承済み）
- DM ヘッダーは「アイコン・名前・メモ・•••」と「ふたりの理性」の2行。口調・一人称・呼び方・ふたりの手札と看破は、メモの一番上の「ふたりのこと」へ。相手の接続切れの印は切れた時だけ
- 段階の帯は1行。補足は畳み、転送の進み具合だけ残す
- 操作シートは高さの45%まで（中身はシートの中でスクロール）
- 相手が貼った1枚は、幅 `min(74vw, 340px)`、高さはスレッドの78%まで（これは全幅共通）。`loading="lazy"` の画像が読み込み前に幅0にならないよう、箱の幅は画面の幅から決める

- 実装コミット: `e4d5901`（全画面DM）、`468c836`（README と公開後の確認スクリプト）。PR [#39](https://github.com/2727-art/GazoStadium/pull/39) をマージし、main は `10169f7`
- 作業と公開は `origin/main`（`525e539`）から切った作業フォルダ `.claude/worktrees/strategy-dm-thread`（`feature/strategy-dm-fullscreen`）で行った。設計は `STRATEGY_DM_THREAD_DESIGN.md` §15
