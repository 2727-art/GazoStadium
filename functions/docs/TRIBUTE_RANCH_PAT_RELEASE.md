# お貢ぎ牧場：管理人が動物を「なでる」と、牧場の小さな直し（2026-10-28）

## 対応内容

第2段の公開のあと、次の改善案を出した。ユーザーの決定（2026-10-28）は「すべておすすめで進めてください」。おすすめとして示した「なでる」と小さな直しを入れた。記念写真（Xに貼る画像）と牧場レベルの番付は、まだ入れていない。設計書は16.14。

### なでる

- 管理人が牧場で動物を押すと、欄に「なでる」が出る。
  - 押すと、その動物の上にハートが一度だけ浮かぶ。そのあとは「今日はなでました」になる。
  - 契約ごとに1日1回まで（日本時間）。出稼ぎに出ている動物は牧場にいないので、なでられない。
- 財布の「牧場をのぞく」に、なでてもらったことが出る。
  - その日: 「今日、ミオ様になでてもらった。」。財布の動物にハートの印も付く。
  - 前の日: 「ミオ様に最後になでてもらった日：10/28」。
- ねらい: 管理人のいちばんの負担はDMの疲れ。言葉を書かずに、ひと押しで「見ている」を伝える。財布には、牧場をのぞく理由になる。
- 入れないもの:
  - 経験値（押すだけで牧場が育たないように）
  - スレッドの出来事、通知
  - なでた回数の比較、なでないと何かが減る仕組み
  - 掲示板の並び（最後に動いた時刻）への反映
- データ: 操作 `ranch_pat`（管理人だけ、進行中の契約で、放牧に同意した財布だけ）。契約の `pattedAt`・`patDayKey`。

### 小さな直し

- 立ち位置は12か所で、契約の数に上限はない。これまでは13頭目から同じ場所に重なっていた。
  - 13頭目からは、同じ立ち位置の右手前・左手前・右奥・左奥に並べ、動物を少し小さく出す（`ranchSpot`）。
  - Lv1・10・30 の絵で、24頭が芝の上に収まることを確かめた。
  - 名前の札は、広い画面でだけ少し小さくする（スマホでは読める大きさのまま）。
- 吹き出しは1頭6秒の持ち回りで、出ているのは約4.5秒。
  - これまでは頭数が多いと2頭が同時に出た。頭数ごとに出方を作り、同時に出ないようにした。
- 動きを減らす設定:
  - 財布の「牧場をのぞく」の1頭の吹き出しと、なでた印を止めて出す。
  - 改善案では「吹き出しがまったく出ない」と書いたが、管理人の画面では、押した動物の吹き出しは前から出ていた。
- 見本: `?tributePreview=ranch-crowd`（20頭）を足した。`ranch` の見本では、1頭が今日なでられている。
