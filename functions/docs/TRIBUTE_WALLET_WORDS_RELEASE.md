# お貢ぎ牧場：言われたい言葉・強さの上限・期間と申し込み直し（2026-10-27）

## 対応内容

貢ぐ側が自分の衝動とやめ方を書いた note の記事（84本）を、今の仕様と照らした（設計書14節）。ユーザーは次の6つを採用した。

- お預け
- 抵抗
- 言われたい言葉
- 言葉の献上と復唱
- 定型文と管理人の自分の言葉
- 続ける手間を減らす

照らした時に見つけた食い違いのうち、次の3つも直すことにした。

- 言葉の強さを財布が決めること
- 管理人が献上を拒めないこと
- 管理人に営業させる言葉

通知と、失うものの重さを見せることは入れない（ユーザー決定）。3つの段に分け、今回はその第1段を公開した。

ユーザーの決定（2026-10-27）:

- お預けの既定は「受ける」
- 差し出された献上の突き返しは作らない
- 延長を申し込めるのは財布だけ

第1段の実装:

- 言われたい言葉
  - 財布は申し込みとスレッドの設定（`set_want_words`）で、5つまで（各12文字）登録できる。
  - 管理する側には、申し込みを受ける前からスレッドの上に出す。入力欄の上に、押すと入る札として並べる。
  - ご褒美にも選べる。記録には言葉そのもの（`reward: "word"`・`rewardText`）を残し、いま登録されている言葉だけを通す。
  - 確認は会話と同じ（外部決済・現金・現実の金額）。言われたくない言葉を含む語は登録できない。
- 言葉の強さは上限
  - 申し込みの項目は「言われてもいい強さ（ここまで）」（甘めまで／普通まで／辛口まで）。
  - 管理する側は、定型文の欄で上限までの強さを切り替えて選ぶ。ご褒美・出稼ぎ命令の一言も、上限までのどの強さからも選べる。
  - 財布の定型文は契約の強さのまま。データ（`tone`）は変えていない。
- 定型文
  - 管理する側に「言い当てる」の場面を足した。
  - 財布の返事にお礼を足した。
  - 甘めの「今日も来てくれる？」を「今日も来るよね？」にした（お願いの形にしない）。
  - ご褒美に「また来てね♡」「好き♡」（甘め）を足した。
- 期間に14日・30日を足した。
- 同じ条件で申し込む
  - 受理された後に終わった契約のスレッドに、財布向けに出す。押すとその管理人の詳細を開き、受付中なら、前の契約の設定を写した申し込みの画面を開ける。
  - 次の3つは写さない（申し込みのたびに財布が選ぶ同意のため）。
    - 請求は断れないことの確認
    - 性的な名目の許可
    - スクショ掲載の許可
  - 契約に管理人の公開ID（`managerPublicId`）を残す。この設定より前の契約には出ない。
- 財布募集の画像
  - 印を「受付中」、右上の札を「財布受付」、見出しを「ACCEPTING WALLETS」にした。
  - 界隈が探すハッシュタグ「#財布募集」は残した。
