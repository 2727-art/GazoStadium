## 対応内容

### 有料アイコンを6枚足した（43〜48）

ユーザーの依頼（2026-10-30）: 「お貢ぎ牧場専用の有料アイコンです(500PAY)。それぞれプレミアム加工をしてください。」（8枚の絵）

- 足した6枚: ミルクティー・瑠璃・琥珀・ネオン・深紅・ルージュ（`avatar` 43〜48、商品ID `ranch_avatar_43`〜`48`、各 500 Pay）。
- 入れなかった2枚:
  - 4枚目: ブレザーにセーラー襟とネクタイの制服の金髪ギャル。
  - 6枚目: ネクタイの制服でツインテール、子どもっぽく見える表情。
  - 未成年に見える絵を、大人向けのこのモードの管理人の顔として売らない線（年齢・学校を連想させない）に当たる。ユーザーには、大人と分かる服装・雰囲気で作り直せば足せると伝えた。
- 加工は `tools/tribute-avatars/premium-icons.py`。最初の番号から順に作り直す形にし、ほかの番号の絵と記録は残すようにした。
  - 暗い絵は、左上の光を弱めて暗さを残す（`sheen`）。
- 持っている飾りは Firestore の `in`（30個まで）で読む。飾りと有料アイコンの商品は今27個で、あと3個まで。

### 金の縁をやめて、ホログラムにした

ユーザーの相談（2026-10-30）: 「金枠ではなく、ソーシャルゲームのURレアカードの様なホログラム効果を持たせることはできますか？金枠だと絵柄を邪魔してしまうのと、各自が好きな枠色が反映されないデメリットがあります。」

見本（金の縁・全面ホログラム・縁寄せホログラム）を見比べたうえで、ユーザーが決めた: 「C 縁寄せホログラムにして、強さは薄め、頻度は少なめでお願いします。またすでに加工済みの白いキラキラのエフェクトを外してください。」

- 形は四角のまま（無料の丸いアイコンと見分ける）。
- 縁は、無料アイコンと同じ印の色。カード編集の「選んでいる」輪も印の色。
- 虹の箔と細かいラメ（`tribute.css`）:
  - 四隅と縁に寄せ、中央は透かして顔の上は絵のまま。
  - `color-dodge`・不透明度 0.38。16秒かけてゆっくり往復する。
- 斜めの光は、12秒に1回、1.5秒ほどで横切る。
- 動きを減らす設定では、箔を止めて光を出さない。
- シェア画像（`tribute-share.mjs`）は、印の色の縁・同じ箔・左上で止めた光を描く。印の色を渡さない画像とストアの見本は、既定の桃色の縁。
- 白いきらめきは、13枚（36〜48）すべてから外した。元画像はすべて手元に残っていて（記録の `sourceSha256` で照合）、そこから作り直した。
- ストアの棚の名前・紹介文・13枚の説明文の「金縁」を「ホログラム」に直した。

コミット:

- 43〜48: `0ef1995`
- ホログラムとキラキラを外した作り直し: `33ccb76`（origin/main）
