# お貢ぎ牧場：スクショ掲載の許可を契約の設定にする（2026-10-26）

## 対応内容

利用者（管理人）の質問: アプリ内のスクショは X に投稿できるか。

ユーザーの判断: 牧場は管理人が財布を支配する場なので、掲載の許可を管理人が会話でお願いすると、支配されたい財布が覚めてしまう。性的な名目・残高報告と同じく、許可を契約の設定にする（案A）。管理人カードに表示させることで差別化も図れる。

- 財布は申し込みの時に「管理人のXに、スクショを載せられてもいい」を選ぶ（`allowScreenshots`、既定は許さない）。財布名や会話が写ること、会話で頼まれることはないこと、いつでも外せるがすでに載ったものはアプリでは消せないことを、チェックの説明に書いた
- 財布のスレッドに「スクショの設定」（申込中・進行中）。財布だけがいつでも変えられる（`set_screenshots`）。変えるとスレッドに出来事（`screenshots_changed`）が残る。管理人は変えられない
- 管理人のスレッドには「スクショ掲載 可」か「スクショ掲載 不可」の札を出す。会話で確かめなくて済む。申し込みの出来事にも「スクショ掲載 可」を出す
- 管理人はカードの「宣言」で「スクショを載せる」を出せる（`card.postsScreenshots`）。掲示板のカード・管理人の詳細・申し込み（「○○は『スクショを載せる』管理人です」の一文も）・財布募集の画像に青い札を出す
- アプリは X への投稿を止められないため、安心ページ（お貢ぎ牧場について）に決まりを足した。財布の写る画面を載せてよいのは財布が許している時だけ、許可はいつでも外せるが載ったものはアプリでは消せない、個人を特定できる情報は載せない
- 設計書（6節「スクショの掲載」・宣言）と README を更新した
- 案B（写っても困らない画面: 言われたくない言葉を畳む・財布名を首輪番号に置き換える）と、通報の理由「同意のない掲載」は入れていない

- 実装コミット: `522f1c1`、確認スクリプト: `23a8b76`（origin/main）。作業フォルダ `.claude/worktrees/ranch-photo-icons`、ブランチ `release/ranch-screenshot-consent`（`origin/main` `2dcf2ad` から、追跡先なし）
