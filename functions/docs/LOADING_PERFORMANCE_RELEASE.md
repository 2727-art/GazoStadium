# 初期読み込み改善・リリース確認（2026-10-28）

## 変更

- 初期HTMLの見出し・画像を再描画せず、操作だけを結び付ける。牧場の保存済みショートカットは必要な部分だけ追加する。
- 初期HTML/CSSをランディングに限定し、画面別のJS/CSSを初回利用時に一度だけ読み込む。生成物は `npm --prefix functions run build:client` で更新する。
- Googleフォントを5種類から2種類へ整理し、描画をブロックしない。移転案内を初期HTMLに含めて後挿入のレイアウト移動を防ぐ。
- 旧市場は購入証書・ランキング・永久実績・公開プロフィールの専用画面に分離。取引・ウォレット・ルームの監視やP2P初期化を起動しない。
- 共通モジュールの異なるURLによる重複取得、旧市場記録の並行取得、通常対戦の重複した待機列heartbeatを整理。成立後の消滅済み待機列への定期書き込みも停止。
- favicon追加。廃止モードの単独JS/CSSとビルド入力をFirebase Hosting/Cloudflareの配信対象から除外。
- 購入履歴・実績・ウォレット・返還済み履歴のデータ移行や削除はない。サーバーの報酬・結果確定・ランキング計算・ルールは変更しない。

## 配信確認と計測

`node functions/scripts/verify-loading-release.cjs <report.json>` は4つの公開originで、初期・遅延モジュールの配信内容とGit HEADの一致、廃止/非公開ファイルの404、faviconの200を確認する。

本番反映後に、改修前と同じLighthouse 13.6.0/Chrome条件でスマホ・PCを各3回計測する。代表値は中央値。LCPは主要コンテンツの表示時間でありページ全体の完了時間ではない。実利用者の計測値ではない。

この検証環境は一部の圧縮応答を展開してブラウザーへ渡すため、LighthouseのtransferSizeをそのまま実回線のダウンロード量とは扱わない。初期JS/CSSの圧縮転送量は、実際のリクエストURLを別途HTTP取得して圧縮された応答バイト数で比較する。個別の生レポートと比較表はこのチャットのperformance-audit成果物へ保存する。
