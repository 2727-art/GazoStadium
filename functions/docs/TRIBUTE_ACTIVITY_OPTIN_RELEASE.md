# お貢ぎ牧場：管理人の「動き」を任意に（2026-10-26）

## 対応内容

「はじめての方へ」の公開（`TRIBUTE_FIRST_STEPS_RELEASE.md`）で、掲示板のカードに「動き」、管理人の詳細に「最後に動いた」を出した。

ユーザーの決定: 最後に動いた時の表示は、管理人が任意で選べるようにする。初期設定は出さない。

- 管理人カードの編集に「最後に動いた時」の欄を足した。チェック「掲示板と管理人の詳細に、最後に動いた時を出す」（`card.showsActivity`）は、初めは外れている
- 出さないカードは、サーバーが相手に時刻を渡さない（`publicCard` の `lastActiveAt` を0にする）。管理人自身のカード（`ownProfileView`）には、自分の時刻を入れる
- 公開の時点では誰も選んでいないので、出ていた「動き」はいったん全員分消える
- 掲示板は、出さない管理人も含めて、これまでどおり最近動いた順に並ぶ。はじめての方へ・失効した申し込みの案内は、「最近動いている管理人に」から「掲示板は最近動いた管理人から並んでいます。上のほうの管理人に〜」に変えた
