# お貢ぎ牧場：牧場基金を管理人の金庫に置き換え（2026-10-24）

## 対応内容

ユーザーの意図: 飾りを買っている管理人はおらず、Pay を牧場基金に上納している管理人も2人だけ。Pay に換金性はないが、貯めること自体を楽しんでいる人がいるので、基金を「Pay を貯める管理人」向けの内容に作り直す。

- 牧場基金（上納・称号・推薦棚・方針の投票・手数料の補填・飾りの売上の20%積み立て）を終え、管理人の金庫に置き換えた（ユーザー決定）
- 金庫を作れるのは、お貢ぎ牧場で累計3人以上の財布から、合わせて1,000 Pay以上を受け取った管理人。最初に入れる時に一度だけ確かめる。推し値市場の売り手としての実績は数えない（ユーザー決定）。公開前の分布（読み取りのみの集計）では28人中9人が当てはまった
- 出し入れは自由、入れる Pay の出どころは問わない（ユーザー決定）。出し入れは AnjuPay の利用履歴に残る（`tribute_vault_deposit`・`tribute_vault_withdraw`）。同じ依頼は二重に動かさない
- 段階: 木箱 1,000 / 金庫 5,000 / 蔵 10,000 / 宝物庫 30,000 / 金の城 100,000 Pay（ユーザー決定）。外に見せるのは段階だけで、額は本人にだけ返す（ユーザー決定）
- 金庫番付: 段階の高い順、同じ段階は先に届いた順、上位30（ユーザー決定）。新しいインデックス（`tributeProfiles`: `vaultTier` 降順・`vaultTierAt` 昇順）を足した。推薦棚のインデックスは記録として残した
- 段階ごとの非売品の飾り（一度届いた段階の飾りは、金庫から出してもずっと使える。ユーザー決定）: 木箱 → 朱肉「古金」 ／ 金庫 → 受取印「千両箱」 ／ 蔵 → 枠「蔵」 ／ 宝物庫 → 枠「宝物庫」 ／ 金の城 → 枠「金の城」（ゆっくり光る。動きを減らす設定では止める）
- 牧場基金の称号（上納者・大上納者・牧場の主）は、実績コレクションの限定称号「牧場基金の限定称号」として残した（ユーザー決定）。データの書き換えはせず、該当する管理人がお貢ぎ牧場を次に開いた時に `tributeHonors` を一度だけ確かめて解除する（上の称号の人は下の称号も持つ）
- 古い画面から届いた基金の操作には「牧場基金は終わり、管理人の金庫に変わりました。画面を読み込み直してください。」と返す。古い画面名 `fund` での指定は金庫へ読み替える
- アカウント画面に「お貢ぎ牧場の金庫を見る」を足した

- 実装コミット: `214e351`、確認スクリプト: `3382031`（origin/main）
- 本体のフォルダはほかのセッションの作業中（`codex/security-hardening-20261023`）のため、前回と同じ作業フォルダ `.claude/worktrees/ranch-photo-icons` に `origin/main` から切ったブランチ `release/ranch-vault`（追跡先なし）で作業した
