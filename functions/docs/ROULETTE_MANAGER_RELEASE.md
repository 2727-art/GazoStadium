## 互換性と限界

- 本番の HTML と静的ファイルは `Cache-Control: max-age=3600` のため、公開前にページを読み込んでいた人は、最大1時間ほど旧画面、または旧いスタイルと新しいスクリプトが混ざった見た目になりうる。保存データの追加項目は任意なので、旧画面との行き来で進行中のセッションや有料利用の復旧は壊れない（旧画面で記録された結果は、命令ごとの一覧の代わりに「最後の命令」1件で表示する）
- iPhone／Android 実機、Safari での確認は行っていない。効果音はアプリの音設定がOFFなら鳴らない
- 有料パックの購入・利用開始・終了の処理は変更していないため、今回エミュレータでは公式無料パックだけを通した
