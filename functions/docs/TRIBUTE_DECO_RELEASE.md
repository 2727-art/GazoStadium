# お貢ぎ牧場：牧場の飾り・牧場用の実績・財布募集の画像（2026-10-09）

## 対応内容

管理人が自分の牧場を飾り、その飾りが掲示板と、財布が X に貼る貢ぎ報告の画像に出ることで、次の財布を呼ぶための仕組み（第1弾）。管理側の AnjuPay の使い道を、牧場基金の上納とは別に作る。

- AnjuPayストアに「お貢ぎ牧場の飾り」の棚（14点・買い切り）。値段は、管理人も最後は運営の財布という扱いで高めにした（ユーザー決定）。購入前に確認を出す。スマホでは棚ごとに横へ送る並び（縦1列だと約4,900pxになり、ほかの商品が遠くなるため。約1,300px）
  - カードの枠: 黒革 5,000 / 鎖 8,000 / 薔薇とレース 10,000 / 金縁の額 15,000 / 玉座 30,000 Pay（冠とゆっくり流れる光。動きを減らす設定では止める）
  - 受取印の形: 角印 3,000 / 小判 4,000 / ハート 5,000 / 王冠 6,000 / 蝋封 8,000 Pay
  - 朱肉の色: 藍 1,000 / 墨 1,000 / 桜 2,000 / 金 3,000 Pay
- 売上の20%はその月の牧場基金に積み、残りは消える（ユーザー決定。上納と同じ割合）。購入と同じトランザクションで `tributeFund/{monthKey}` の `balance` と `shopIncome` に足す。牧場基金の画面に「飾りの売上から」を出す。ストアの「運営への献上」のような見せ方は、管理人の承認欲求を削ぐおそれがあるため入れない（ユーザー決定）
- 管理人カードの編集で、持っていない飾りも試着でき、その場で買える。試着中は保存できず、「試着をやめる」で持っていない飾りだけ保存済みの飾りに戻る。保存の時に、サーバーが購入（`economyPurchases`）を確かめる
- 枠は掲示板・管理人の詳細・招待リンクで着いた画面に出る。中の人の札・入場料・管理中の人数は、どの枠でも同じ位置と色。並び順・カードの大きさ・手数料・番付は変えない。飾りに文字は入れない
- 受取印は、押した時の形と朱肉を献上とレシートに残す（`sealShape`・`sealInk`）。あとで替えても過去の印は変わらない。管理人を伏せた貢ぎ報告の画像は標準の印
- 牧場のカードに出す実績（3つまで）: 解除した実績から選ぶ（ほかの遊びの実績も可）。実績コレクションの展示とは別。保存の時にサーバーが解除済みかを確かめる
- 財布募集の画像（1080×1350）: 「管理人として」の招待リンクの欄から作る。飾った枠・中の人の札の全文・型・称号・今日のひとこと・紹介・入場料・管理中・今月の財布・実績3つと、自分の受取印で押した「募集中」。管理人の端末の中で canvas に描き、サーバーへは送らない。URL は入れず（招待リンクは投稿の文）、「上限と解約は財布が握る」「AnjuPay だけ・現金なし」と AnjuPay の表記を必ず入れる。枠は SVG 画像を重ねず canvas で描く（端末によって書き出せなくなるのを避けるため）
- モックからの変更: 募集画像の「募集中」の印を、カードの右下の外へ移した（枠の縁、特に金縁の上の金の朱肉が読めなかったため）。ストアの棚のスマホでの並び（上記）

- 実装コミット: `74d7c33`、確認スクリプト: `8bb277d`（origin/main）
